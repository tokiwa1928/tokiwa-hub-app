## 納品書（3面・1枚）

上から **納品書（控）／納品書／受領書** の3面。控と納品書は同じ内容、受領書は金額を出さず受領印欄。

| 項目 | 例 | 出どころ |
|---|---|---|
| No. | `DE08288` | 納品書番号。`DE` + 5桁連番 |
| 宛名 | 有限会社オガサ自動車 御中 | 取引先マスタ |
| 得意先コード | `CU05819` | 取引先マスタ |
| 締め日 | `締め日：末` | 取引先マスタ（請求方法） |
| 日付 | 2026年9月14日 | 納品日 |
| 明細 | 品名／数量／単位／単価／金額／注文No. | 受注（複数の受注番号をまとめて1枚にできる） |
| 文言（納品書） | いつもご愛顧いただきありがとうございます。下記の通り納品いたします。 | 固定 |
| 文言（受領書） | 下記の通り受領いたしました。 | 固定 |
| 受領書の列 | 品名／数量／単位／受領印 | 金額なし |

**1枚の納品書に複数の受注番号が載る**（例では a106853×2行・a107006・a107008）。
納品書は「得意先×納品日」の単位で、受注の明細行を束ねる。

## 番号の体系（GEN と揃える）

```
受注   a108216        FileMaker の伝票番号と同じ
納品書 DE08288        DE + 5桁
請求書 BI04053        BI + 5桁
入金   PI03695        PI + 5桁
発注書 PO06221        PO + 5桁
受入   AC260700039    AC + 年月 + 5桁
```

Hub で発行するときは **GEN の続き番号から始める**。GEN の最新番号は「📥 GEN 取り込み」で分かる。

## Hub が引き取る範囲（本多さん 2026-09-11）

1. 納品書・受領書
2. 請求書（締め請求・都度請求）
3. 消込・入金登録
4. 外注・仕入登録
5. 現金購入（仕入・外注と同じ画面で）

### 積み残し（2026-09-11 決定）

**まず製造と、納品書・請求書の実運用。** 以下は後回し。

- **預金口座・クレジットカードの取り込み** —— 会計士への提出のため残高も見たい。
  銀行・カードの API は登録事業者にしか開かれていないので、直接はつなげない。
  道は2つ: ①各行・各社の明細 CSV を放り込む（無料・すぐ）、
  ②freee／マネーフォワード／Moneytree を間に挟んで API で読む（月額あり・自動）。
  どちらでも取り込んだ後の中身（消込・残高・提出）は同じなので、①で始めて後から②に差し替えられる。
- **入金消込の自動提案** —— 銀行明細（振込人名・金額・日付）と請求書を突き合わせる。取り込みができてから。
- **freee と かんたんクラウド（MJS）** —— 直接の紐づけは無い模様。仕訳 CSV の受け渡しならできる。
  会計士がどちらを使うかで変わるので、着手時に確認。
- **メールから経費を拾う** —— 注文確認メールから品名・金額・日付を拾って現金購入の下書きにする。便利機能なので後で。

## 流れ

```
受注（FileMaker）
  └→ 納品書 DE…（得意先×納品日で受注の明細を束ねる）
        └→ 請求書 BI…（締め：締め日までの納品書を束ねる／都度：納品書1枚）
              └→ 入金 PI…（請求書番号で消し込む）
```
