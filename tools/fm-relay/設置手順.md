# FileMaker 中継の設置手順

Hub の画面から FileMaker のデータを直接読み書きするための中継を、
Google Apps Script に置きます。**10分ほどで終わります。**

```
Hub（ブラウザ）→ この中継（GAS）→ FileMaker Cloud Data API → トキワ印刷DB
```

---

## 1. プロジェクトを作る

1. <https://script.google.com/home> を開く（**@tokiwap-group.com のアカウントで**）
2. 左上の **新しいプロジェクト**
3. 左上のプロジェクト名を **`FileMaker中継`** に変える

## 2. コードを貼る

1. `コード.gs` の中身を全部消す
2. このフォルダの **`コード.js`** の中身を全部貼る
3. 保存（Ctrl+S）

## 3. 鍵を入れる

**更新トークンを画面に出さずに渡します。** このPCで次を実行してください。

```bat
C:\Users\honda\dev\tokiwa-hub-app\tools\fm-sync\更新トークンをコピー.cmd
```

クリップボードに入るので、そのまま貼り付けられます。

Apps Script の画面で **⚙ プロジェクトの設定** → 一番下の **スクリプト プロパティ** →
**スクリプト プロパティを追加** で、次を入れます。

| プロパティ | 値 |
|---|---|
| `FM_REFRESH_TOKEN` | （上でコピーしたもの） |
| `ALLOWED_DOMAIN` | `tokiwap-group.com,tokiwap.co.jp` |
| `DEV_KEY` | 適当な長い文字列（**動作確認が済んだら消します**） |

> `ALLOWED_DOMAIN` は**社員が Google にサインインするときのドメイン**です。
> 本多さんの Claris ID は `@tokiwap.co.jp`、Hub の既存 GAS は `tokiwap-group.com` なので、
> 両方書いてあります。片方しか使っていなければ、使っている方だけにしてください。
> ここに書いていないドメインの人は、URL を知っていても中継を通れません。

`LOG_SHEET_ID` は任意です。入れると「誰がいつ何を書いたか」がそのスプレッドシートに残ります。

## 4. 公開する

1. 右上の **デプロイ** → **新しいデプロイ**
2. 歯車 → **ウェブアプリ**
3. 次のように設定

   | | |
   |---|---|
   | 次のユーザーとして実行 | **自分** |
   | アクセスできるユーザー | **全員** |

4. **デプロイ** → 権限を求められたら承認
5. 出てきた **ウェブアプリの URL** を控える（`https://script.google.com/macros/s/.../exec`）

> **「全員」で不安になると思いますが、これで正しいです。**
> 中継は Google の ID トークンを検証して、`@tokiwap-group.com` 以外を全部拒否します。
> URL を知られても、社外の人には何もできません。
> 「組織内の全員」にすると、GitHub Pages から呼ぶときに Cookie の制約で通らないため、
> この形にしています。

## 5. URL を教えてください

こちらで動作を確認します。

## 安全のしくみ

| | |
|---|---|
| 誰が呼べるか | Google でサインインした `@tokiwap-group.com` のみ |
| 書ける項目 | **入力可の198項目だけ**。計算64項目と伝票番号は書けない |
| 二重更新 | 保存時に `modId` を送る。誰かが先に更新していたら FileMaker が弾き、画面に知らせる |
| 記録 | `LOG_SHEET_ID` を入れると、誰がいつ何を書いたかが残る |

## 動作確認が済んだらやること

- **`DEV_KEY` を削除する。** これがある間は、鍵を知っていればサインイン無しで通れます
- 実運用に入る前に、中継用の Claris ID を別に用意して `FM_REFRESH_TOKEN` を差し替える

## 更新トークンが切れたら

有効期間は1年です。切れると中継が

> Claris のトークンを更新できません（更新トークンの入れ直しが要ります）

と返します。そのときは、このPCで

```bat
C:\Users\honda\dev\tokiwa-hub-app\tools\fm-sync\fm-connect.cmd
```

を実行して入れ直し、手順3で `FM_REFRESH_TOKEN` を差し替えてください。
