LINE WORKS 連携（カテゴリーの自動付け替え）の入れ方

Hub から LINE WORKS のノートに入れたあと、ノートの「カテゴリー」（1-2.メディア部作業待ち、4.校了 など）を自動で付け替える仕組みです。Chrome に小さな拡張機能を 1 回入れます。入れていない PC では、今までどおり「カテゴリーを変えてください」の案内が出ます。

この PC の状態を確かめています…

1. ファイルをダウンロードして展開する

lw-ext.zip をダウンロード

ダウンロードした lw-ext.zip を右クリック →「すべて展開」。展開した lw-ext フォルダは、消さずに残る場所（例: C:\Tokiwa\lw-ext）に置いてください。フォルダを消すと拡張機能も消えます。

2. Chrome に読み込む

  1. Chrome のアドレス欄に chrome://extensions と入れて開く
  2. 右上の「デベロッパー モード」をオンにする
  3. 左上の「パッケージ化されていない拡張機能を読み込む」を押す
  4. 展開した lw-ext フォルダを選ぶ（中に manifest.json があるフォルダ）
  5. 一覧に「Tokiwa Hub × LINE WORKS」が出れば完了。このページを読み直すと、上の枠が「入っています」になります

3. 使い方

いつもどおり Hub の問い合わせから「💼 LW ノートへ」→「ノートに入れる」。⑤ でカテゴリーを選んであれば、LINE WORKS のノートが別タブで開き、上に帯が出て、カテゴリーを付け替えてからタブが閉じます。

帯の色意味
緑付け替えました。タブは自動で閉じます（閉じないときは閉じて構いません）
赤自動で付け替えられませんでした。理由が書いてあります。その場で「移動」から手で付け替えてください

うまくいかないとき

  • LINE WORKS にログインしていないと動きません（別タブでログインしてから、もう一度）
  • グループを初めて使うときは、Hub がそのグループの「ノートの番号」を知らないので、ノートの URL を 1 回貼る案内が出ます。貼ると次からは自動です
  • 拡張機能を新しくするときは、新しい zip を展開して同じ場所に上書きし、chrome://extensions で「更新」を押します
