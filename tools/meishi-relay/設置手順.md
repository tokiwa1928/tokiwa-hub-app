# 名刺中継（Hub ⇔ 旗艦PC の Illustrator）

Hub の「📇 名刺 差し替え作成」（`tools/meishi-sakusei.html`）から、どの PC・スマホでも
名刺の .ai と校正PDF を作るための中継です。

```
Hub（ブラウザ）── Google サインイン ──▶ この中継（GAS）
   ▲                                      │ 依頼を書く
   │ 結果・校正PDF                         ▼
   └──────── 共有ドライブ「トキワ印刷株式会社/50_メディア/DTP自動化/名刺」
                     ▲ │（Google ドライブ パソコン版で W: に同期）
                     │ ▼
             旗艦PC（rhonda）のウォッチャー → Illustrator → .ai・校正PDF・確認結果
```

## 残っている作業（1回だけ・2分）

### ① スクリプトを承認する

編集画面を **info@tokiwap-group.com** で開き、関数の一覧から **`セットアップ確認`** を選んで **実行**。
初回に権限の承認画面が出ます（Google ドライブ・外部への接続）。承認してください。
**これをしないと外から呼べません**（いまウェブアプリが 403 なのはこれが理由）。

実行ログにこう出れば完了です（受け渡しフォルダの ID は自動で探して覚えます）。

```
○ 受け渡しフォルダ: 名刺（ID ...）
○ run / jobs / out / records / templates フォルダ
○ テンプレート 1件: 中村建設株式会社
○ 旗艦PCの最終確認: 2026-10-13T...
○ WEB_CLIENT_ID: 301364298857-...
```

> 「受け渡しフォルダが見つかりません」と出たら、info@ に共有ドライブ「トキワ印刷株式会社」の
> 権限があるか確認するか、スクリプトプロパティ `ROOT_FOLDER_ID` に「名刺」フォルダの ID を入れてください。

### ② Hub に反映（push）

`tools/meishi-sakusei.html` と `tools/meishi-relay/` を main に入れ、`index.html` の
`TOOLS_REGISTRY` に1行足します（`tools/meishi-relay/TOOLS_REGISTRY_追加.txt`）。

- `Downloads\JK22_AI\jk22_watcher.vbs` を更新し、`run\inbox.txt` に書いたフォルダ

1. NAS のテンプレート .ai を旗艦PC にコピーし、差し替える文字枠に名前を付ける（tag）
2. `<ID>_tpl.json` を作って受け渡しフォルダの `templates` に置く → 画面の一覧に出る
